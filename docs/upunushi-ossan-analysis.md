## 調査目的

検証済みの登録者推移（Wayback 18点＋概要ページ、全観測を対象IDで確認）から、このチャンネルは「減少」ではなく、三つの局面を持つ成長であることが分かった

1. 2021年7月〜2022年6月：1日約230〜290人の急伸（1,620人 → 約7.8万人）
2. 2022年後半〜2025年前半：1日約90〜170人の安定成長
3. 2025年後半〜2026年10月：1日約50〜75人に鈍化（25.1万人）

一方で、1本あたりの再生数の中央値は2021年の約5万回から2025年の約22万回へ伸び、2026年も高水準にある
したがって、この調査の問いは次の二つとする

- **急伸期（2021年後半〜2022年前半）に、何が登録者を集めたのか**
- **1本あたりの再生は伸びているのに、2025年後半から登録者の伸びが鈍化しているのはなぜか**

加えて、動画ごとの再生の差を説明する題材・形式の特徴を、代表動画の内容分析から仮説として立て、標本外の動画で検証する
