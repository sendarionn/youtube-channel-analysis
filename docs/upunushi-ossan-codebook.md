# たくみっく コーディング基準

## テーマ（`annotations/labels_semantic.csv`）

タイトルが主に問う対象を1テーマに分類する。複数に該当する場合は次の順を優先する

| 順 | コード | 名称 | 判定基準 |
|---|---|---|---|
| 1 | shinkansen | 新幹線・リニア | 新幹線・リニアの路線・駅・計画・運行 |
| 2 | road | 道路・経路 | 高速道路・国道・バイパスの計画や開通、車での経路（走行回） |
| 3 | rail | 在来線・鉄道政策 | 在来線・私鉄・地下鉄・LRT・ICカード・きっぷ・鉄道の制度や技術 |
| 4 | urban | 都市・地域経済 | 都市・自治体・ニュータウン・商業施設・温泉地などの盛衰 |
| 5 | aviation | 航空・空港 | 空港・航空 |
| 6 | society | 社会・国際・技術 | 交通・地域以外（国際情勢、IT、生活） |
| 7 | other | その他 | 告知・旅行記・上記に当たらないもの |

- 規則の語彙は `config/channels/upunushi-ossan.toml` の `[theme_rules]`（v2）
- 境界：新幹線と地域の両方を扱う動画（例「北陸新幹線は好調でも市内中心部が空洞化」）は、規則では新幹線、人の判定では都市になりやすく、不一致の主な原因になる

### 検証（`annotations/theme_validation.json`）

| 規則 | 開発用の抜き取り（seed=1、100本） | 検証用の抜き取り（seed=2、100本、重複なし） |
|---|---|---|
| v1（Codex 作成、2026-10-20） | κ=0.56、一致率0.66 | κ=0.51、一致率0.61 |
| v2（語彙を追加、2026-10-21） | κ=0.77（改訂に使ったため過大評価） | **κ=0.66、一致率0.76** |

- 判定者：分析エージェント1名。タイトルのみを見て、再生数は伏せた。ただし調査中に一部の動画の実績を見ている
- 未分類（その他）は79本（8%）で、目安の5%を超える

## 代表動画の内容分析（`annotations/phase3_coding.csv`）

標本：`annotations/phase3_sample_frozen.csv`（相対再生指数の上位・中位・下位から各12本。2026-10-20 に Codex が選定し、字幕を取得した時点で固定）

| 列 | 定義 |
|---|---|
| format | 解説型（なぜ・経緯を説明）／走行型（車・列車で経路を走る）／仮定型（もし〜なら）／時事外（交通・地域以外）／反応型（海外の反応）／論争型（マナーなどの賛否） |
| hook_type | 冒頭30秒の掴み：question・claim・news |
| regional_stakes | 実在の地域・事業者の得失（損した・後悔・除外・衰退など）を問う（0/1） |
| new_route_info | 新規開通・短縮ルートなど移動に使える新しい情報（0/1） |
| hypothetical | 仮定・妄想が主題（0/1） |
| off_genre | 交通・地域以外の話題（0/1） |
| field_footage | 自分で撮った現地・車窓映像の比率：high・mid・low（フレーム一覧の目視） |
| humor | 「うp主のおっさん」の台詞・ツッコミの頻度：high・mid・low |
| pun_ending | 終盤に「おっさん」の駄洒落・説法で締める（0/1） |
| subs_checked・visual_checked | 字幕・映像フレームを確認した（0/1） |
| notes | 構成のタイムライン |

- 2026-10-20 の Codex による6本分の記述は `phase3_coding_codex_6.csv` に保存
