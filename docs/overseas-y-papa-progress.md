各Phaseの方法・結果・制約・未完了事項

## Phase 1 データ収集

### 方法

| 対象 | 方法 | 保存先 | 取得日時(UTC) |
|---|---|---|---|
| 全動画のメタデータ（351本） | yt-dlp でウォッチページを1本ずつ取得、`lang=ja` で原題を取得 | `raw/ytdlp_videos/20261019T120656Z/` | 2026-10-19 12:07〜12:40 |
| サムネイル | `i.ytimg.com/vi/<id>/hqdefault.jpg` | `raw/thumbnails/hqdefault/`（Git管理外） | 2026-10-19 12:40頃 |
| 現在のチャンネル情報 | `/about` ページHTML | `raw/channel_page/` | 2026-10-19 12:16 |
| 過去のチャンネル情報 | Wayback Machine CDX → 当時のHTML | `raw/wayback/`（2026-06-10〜10-10 の19件） | 2026-10-19 12:11 |
| 比較候補 | YouTube 検索10語×30件 | `raw/peer_search/` | 2026-10-19 12:15 |

### 結果

- 通常動画350本・Shorts1本・ライブ配信0本
- 初投稿 2026-02-12（チャンネル開設日は 2022-02-23 だが、それ以前の公開動画はない）
- 登録者 16.7万人、総再生 4,157万回（2026-10-19 直接取得）
- 登録者の観測点：Wayback 10点（2026-06-10 3.32万人〜10-10 13.3万人）＋ 節目告知動画6本（1万・2万・5万・10万・15万・16万人）

### 制約

- YouTube Data API のキーがないため yt-dlp を使用（取得項目は API と同等）
- 公開後の日次再生数、視聴維持率、CTR、トラフィック元、登録転換率は公開データにない
- 統計サイト（Social Blade・Yutura・vidIQ）は Cloudflare 等で 403、Wayback にも保存なし
  - 2026-06-10 以前の登録者数は、節目告知動画のタイトル（自己申告）しかない
- 登録者数はページ表示値のため3桁に丸められている（例 33.2k）
- 2026-03-16〜03-26 の投稿空白は、動画「（復活）このチャンネルが詐欺扱いされ吹っ飛びました」によるとチャンネル停止期間。停止中に失われた動画があったかは確認できない

## Phase 2 定量分析

### 方法

- 公開時期の差の補正：相対再生指数 = 再生数 ÷ 同種別（通常/Shorts）の前後10本の再生数中央値
  - 公開7日未満の動画は比較から除外（`mature`）
  - Wayback の動画一覧から、公開7〜14日時点の再生数は現在の約5割と分かった（`phase2_tables.md` 8章）。指数は「初速」ではなく「現在までの累計の相対値」
- テーマ・内容特徴：全351本をタイトルから手作業でコーディング（[基準](overseas-y-papa-codebook.md)）
- タイトル要素：規則・辞書ベースで自動判定（`analyze/title_features.py`）
- 検定：Mann-Whitney U（BH補正）、Kruskal-Wallis、OLS（HC3）で交絡を同時調整
- 期間：登録者の節目告知（1万・5万・10万）で P1〜P4 に区切る

### 結果（詳細は [phase2_tables.md](../reports/overseas-y-papa/phase2_tables.md)）

- 国際比較・ランキング型（中央値の比 1.82倍、補正後 p=0.001）と日本との結びつけ（1.34倍、p=0.004）が有意
- 日本への言及のうち「日本に肯定的・安心させる」論調は中央値 2.45、否定的 1.04（p=0.005）
- タイトルの疑問符・数字・【】・文字数は差なし
- 尺は長いほど指数が高い（16〜20分 1.27、5〜10分 0.86、回帰でも1分あたり +3%）
- 朝6〜7時台投稿は中央値 1.19 対 0.92 だが、回帰で期間・テーマを調整すると有意でない（p=0.26）
- 高評価率と相対再生指数は負の相関（Spearman -0.60）
- サムネイルの色・明度などの客観特徴は上位と下位で差なし（テンプレート化）。目視では上位24本の50%、下位24本の12.5%がサムネ文字に「日本」を含む

### 制約

- テーマ・論調のコーディングは1名で実施し、再生数を知った状態で行った（特に japan_tone）
- 相対再生指数は近傍の動画に依存し、同日に複数投稿した場合などは互いに影響する

## Phase 3 内容分析

### 方法

- `analyze/select_sample.py` で相対指数の上位20%・40〜60%・下位20%から、期間×3本、期間内でテーマが重複しないよう各12本を選定
  - P4 の下位候補は2本しかなく、P1 から1本補充
  - 最大ヒットのハッカーホイホイ（公開7日未満で選定外）を参考事例として追加（`annotations/phase3_extra.json`）
- 字幕：YouTube 自動字幕（json3）を37本取得（Git管理外）
- 映像：360p で一時取得し、ffmpeg で15秒ごとのフレーム抽出とシーン変化（閾値0.3）によるカット検出を行い、映像ファイルは削除
  - yt-dlp は JS ランタイムがないと一部形式が 403 になるため、node を使うよう対応
- 自動計測（`phase3_metrics.csv`）：話速、チャンネル紹介・構成予告・冒頭への回帰・登録依頼の出現時刻
- 手作業コーディング（`annotations/phase3_coding.csv`）：字幕要約と全37本のフレーム一覧を目視して判定

### 結果

- 冒頭の掴み → チャンネル紹介（中央値27〜41秒）→ 本編 → 定型の締め、の型は群に関係なく共通
- 話速は全群で毎分約330字
- 数値データの密度が高い回：高群8/12、中群5/12、低群1/12（手作業）
- 寸劇形式は低群のみ3本、初期の自宅vlogは低群に3本
- 映像は P2 以降、群に関係なく「街歩きの環境映像＋猫アバター＋常時字幕＋数字カード」

### 制約

- 構成予告は手作業と自動検出の一致が27/37本で、群間差の向きが一致しない → 判定保留
- カット検出はスライドのフェード切替を捉えられず、映像テンポの比較には使えない
- 各群12本の小標本

## Phase 4 類似チャンネル比較

### 方法

- 検索語10個（`config/channels/overseas-y-papa.peers.toml`）の YouTube 検索上位30件に複数回出現した個人系の解説チャンネルから3件を選定
- 各チャンネルの直近40本（通常動画は Shorts を除く）のメタデータ、サムネイル、現在の概要ページ、Wayback の月1件のスナップショットを取得
- 各チャンネル3本（直近40本の再生上位・中央・下位）の字幕とフレームを取得し、構成・映像・ナレーションを目視比較

### 結果（[phase4_tables.md](../reports/overseas-y-papa/phase4_tables.md)）

- 投稿頻度：海外Yパパ 週12.7本、比較 週0.5〜1.7本
- 尺中央値：12.1分 vs 20.4〜41.8分
- 高評価率 2.56% vs 1.21〜1.64%、コメント率 0.41% vs 0.08〜0.19%
- タイトルに「日本」33% vs 3〜18%、疑問符 20% vs 49〜87%
- 開始8か月時点の登録者は比較チャンネルより多いか同等

### 制約

- ジオグラのメンバー限定5本は取得できず、32本で比較
- Wayback の過去値に、保存時のページが古い登録者数を表示している異常値があり、過去最大値の7割未満に急減した観測を除外した
- 現在の概要ページの登録者数の解析で、新レイアウトのヘッダー表記（@ハンドル付き）を読めず、おすすめチャンネルの値（5.55万人）を誤って取得していた不具合を修正済み（正しくは107万人、回帰テストあり）

## Phase 5 仮説検証

- 19個の仮説を4段階（発見・クリック・視聴継続・再訪）に分け、支持・反証・代替説明・確信度・再現可能性を整理した（[FINAL_REPORT.md 7章](../reports/overseas-y-papa/FINAL_REPORT.md)）
- 棄却：時事性、タイトル技法、サムネイルのデザイン、構成の型（いずれも動画間の差としては説明力なし）
- 支持：国際比較・ランキング型、日本への引き寄せ（特に安心させる逆張り）、個別ヒットによる段階的な登録者増、高頻度投稿による底上げ（交絡あり）、エンタメ回の不振
