# リュウジのバズレシピ 試験コーディング基準

`data/ryuji-buzz-recipe/annotations/labels_manual.csv` の定義
2026-10-21、再生数を伏せた盲検シート（`annotations/blind/sheet_20261021_seed0.csv`）で分析エージェントが判定
試験調査のため1名・1回の判定で、一致率は未算出

## theme

| コード | 名称 | 判定基準 |
|---|---|---|
| R | レシピ実演 | 本人のオリジナル料理の作り方 |
| C | 市販品・店の再現とジャッジ | 市販品・チェーン店・他者の料理を食べて評価する、または再現する |
| F | 騒動・本人の報告 | 炎上・騒動への言及、活動に関する報告 |
| K | 企画・コラボ・PR | 大食い企画、ゲスト、商品の告知 |
| L | 生配信・記念告知 | 生配信、登録者記念（内容比較から除外） |
| X | タイトルから判断不能 | 「生きてて良かった」など（内容比較から除外） |

## controversy

タイトルが炎上・騒動・酷評・批判に言及している（0/1）
