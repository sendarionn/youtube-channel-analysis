## labels_manual.csv（全351本、タイトルと公開順の文脈から判定）

### theme（1本につき1つ、主題で判定）

| コード | 名称 | 判定基準 | 例 |
|---|---|---|---|
| G | 国際情勢・地政学 | 国家間関係、外交、軍事、領土、国際機関 | 「敵国条項」ですか。優等生の日本が鍛えるべきビンタ力 |
| E | 経済・金融・投資 | マクロ経済、金利・為替、株式、企業業績、富裕層の資産、税 | 日本に「金利のある世界」が来ると、何がやばいの？ |
| A | AI・テック解説 | AI・半導体・宇宙などの技術ニュースや仕組みの解説（業務での使い方以外） | AIの「蒸留」ってなんですか？ |
| P | AI実務ハウツー | AIを仕事でどう使うかの手順・考え方 | 【AI実務中級】AIの「グラウンディング」についてまず理解する |
| S | サイバー・詐欺 | ハッキング、暗号、詐欺、情報セキュリティ | ハッカーホイホイ作ったら48時間で1万回来た |
| D | 人口・社会・教育 | 人口動態、移民、教育、社会制度、国民性 | 【豊かじゃない国も】人口統計マニアの僕が語る少子化の理由 |
| L | 海外生活・現地 | NZ・シンガポールなど居住地の生活・現地レポート | ニュージーランドの子育てがしんどい |
| Z | 雑談・告知・音楽 | 個人エピソード、登録者記念、楽曲・MV、ゲーム、グルメ | 【祝15万人達成！】トイレ行きたい |

経済と国際情勢が重なる場合は、タイトルが問うている主語で判定する
（「中国経済はヤバいの？」は E、「米中、お互いに一つだけほしいもの」は G）

### 特徴フラグ（0/1、複数可）

| 列 | 定義 |
|---|---|
| japan_angle | タイトルが日本・日本人・日本企業との関係を明示している |
| intl_compare | 複数国の比較、ランキング、国別コンテスト形式 |
| timely | 特定の直近ニュース（発表・事件・上場・決算など）を起点にしている |
| counterintuitive | 通説・直感と逆の結論を示している（「〜じゃないよ」「実はマシ」「だから何？」） |
| anxiety | 危機・損失・脅威を前面に出している |
| music_format | 時事テーマをラップ・歌で扱っている |
| japan_tone | japan_angle=1 の場合のみ：pos（日本は思われているより良い・強い・好かれている、または不安を否定する）、neg（日本の衰退・失敗・脅威）、neu（どちらでもない） |

japan_tone は Phase 2 の途中（Phase 3 の字幕を読んだ後）に追加した項目
コーディング時点で再生数を知っていたため、判定が実績に引きずられた可能性がある

## thumbnail_codes.csv（相対再生指数の上位24本・下位24本）

| 列 | 定義 |
|---|---|
| thumb_text | サムネイル内の文字（目視で転記、改行は空白） |
| thumb_style | cat_photo（猫アバター＋写真/画像背景）、text_only（黒地に文字のみ）、cat_chart（猫＋グラフ）、news_parody（ニュース番組風）、cat_screen（猫＋画面キャプチャ） |
| thumb_mentions_japan | サムネイル文字に「日本」「日本人」「日本車」などを含む |

## phase3_coding.csv（Phase 3 の37本、字幕と映像フレームの目視で判定）

| 列 | 定義 |
|---|---|
| hook_type | 冒頭30秒の掴み：question（問いかけ）、claim（意外な主張の提示）、story（個人体験）、experiment（実験・実演）、news（ニュース紹介） |
| promise_by_s | 「この動画で何がわかるか」を言い終えた秒数（目視、概算） |
| conclusion_position | 結論を最初に示すか：upfront（冒頭）、middle、end、none |
| structure | 本編の型：explain（仕組み解説）、list（要因列挙）、compare（国際比較・ランキング）、narrative（時系列の物語）、experiment（実験記録）、qa（問いへの回答） |
| data_density | 数値・統計・出典の提示：high（1分に1つ以上）、mid、low |
| japan_link | 本編で日本の視聴者自身への影響・日本との比較に触れるか（0/1） |
| visual_main | 主な映像：infographic（図表・データカード）、illustration（猫イラスト）、photo（写真・AI生成画像）、ui_demo（画面操作・ダッシュボード）、text（文字のみ） |
| humor | 比喩・ツッコミ・自虐の頻度：high、mid、low |
| callback_end | 終盤で冒頭の問いに戻って答えるか（0/1） |
| end_cta | 終盤に登録・高評価の呼びかけがあるか（0/1） |
| notes | 構成のタイムライン（分:秒 区間名） |
