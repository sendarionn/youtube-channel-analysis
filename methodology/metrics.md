# 指標の定義と前処理

バージョン 1.1.0。定義を変えた場合は CHANGELOG に記録し、旧バージョンの結果とそのまま比較しない

## 前処理（`analyze/build_dataset.py`）

| 項目 | 定義 |
|---|---|
| 動画の種別 `kind` | Shorts タブ由来または `media_type=short` → `short`、ライブ配信の履歴あり → `live`、それ以外 → `video`。比較は種別ごとに行う |
| 公開日時 | yt-dlp の `timestamp`（UTC）。ない場合は `upload_date` の0時 |
| 現地時刻 `*_jst` | 設定 `timezone` の時刻（既定 Asia/Tokyo）。列名は v1.0 との互換のため `_jst` のまま |
| 経過日数 `age_days` | 取得時刻 − 公開日時（日） |
| `mature` | `age_days ≥ min_age_days`（既定7）。再生数がまだ大きく動く動画を比較から除く |
| 尺 | 秒、分（`duration_min`） |
| 高評価率・コメント率 | 高評価数 ÷ 再生数、コメント数 ÷ 再生数。コメント無効の動画は欠損 |
| タイトル特徴 | `analyze/title_features.py` の規則・辞書（日本語向け）。ハッシュタグは除いて判定 |

## 再生実績の指標

### 相対再生指数 `rel_index`（主指標）

```
rel_index = その動画の再生数 ÷ 同じ種別の前後 window 本（公開順、自身を除く）の再生数の中央値
log_rel = log2(rel_index)
```

- window は設定 `neighbor_window`（既定10）。端は片側だけで計算
- 1.0 が「その時期の標準」。チャンネル規模の時期差を吸収する
- 公開後7日・30日の再生数が公開データにないための代替。「初速」ではなく「取得時点までの累計の相対値」
- 限界：同日に複数投稿すると近傍が互いに影響する。近傍が少ない時期（投稿開始直後・長い休止の前後）は不安定

### 頑健性チェックで使う代替指標（`analyze/robustness.py`）

| 指標 | 定義 | 目的 |
|---|---|---|
| window 5・20 の相対指数 | 近傍本数を変える | window の選び方への依存を確認 |
| 経過日数・公開月で調整した残差 | `log(再生数) ~ log(経過日数) + C(公開月)` の OLS 残差 | 近傍の定義に依存しない比較 |

主要な結論は、全ての指標で向きと有意性が保たれることを確認してから書く

### 使わない指標

- 累計再生数の単純比較：公開時期の差を含むため
- 1日あたり再生数（再生数 ÷ 経過日数）：新しい動画ほど過大になる。参考値として `views_per_day` は残す

## 成長過程の指標

| 指標 | 定義 | 出典 |
|---|---|---|
| 登録者数・総再生数・動画数 | チャンネルページの表示値（丸めあり） | 概要ページの直接取得、Wayback |
| 異常値 `anomaly` | それまでの最大値の 0.7 倍未満に急減した観測（保存ページが古いキャッシュ値を表示する例があるため） | `wayback_parse.flag_anomalies` |
| 1日あたり登録者増 | 隣接する観測の差 ÷ 日数 | — |
| 節目告知 | タイトルに「登録者」「達成」「万人」と「N万」を含む動画（自己申告。公開日は到達日以降） | タイトル |
| 期間区分 | 設定 `period_milestones` の節目告知の公開日で区切る。告知がなければ公開順に4等分 | — |
| 再生の蓄積速度 | Wayback の動画一覧に表示された再生数 ÷ 現在の再生数（公開からの経過日数別） | Wayback |

## 検定と効果量

| 比較 | 方法 |
|---|---|
| 2群（特徴の有無） | Mann-Whitney U（両側）、効果量は中央値の比と順位双列相関 |
| 3群以上（テーマ・尺区分など） | Kruskal-Wallis |
| 多重比較 | 同じ表の中で Benjamini-Hochberg。報告書全体での補正は未実施（レビュー R7） |
| 交絡の同時調整 | `log_rel` の OLS、HC3 標準誤差。説明変数はテーマ・フラグ・疑問符・数字・尺（中心化）・定時枠・期間 |
| 分類の一致 | Cohen's κ（2値・多値） |

少数（各群5本未満）の比較では検定しない
